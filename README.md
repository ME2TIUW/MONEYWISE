# MoneyWise

## Overview

MoneyWise is a comprehensive mobile financial tracking application developed as a university thesis project. It empowers users to take control of their personal finances through intelligent automation, modern UI design, and seamless expense management.

## Tech Stack

- **Frontend/Mobile Framework:** Flutter 3.38.6 (Dart 3.10.7)
- **State Management:** Provider
- **Backend & Services:** Firebase (Authentication, Cloud Firestore, Firebase Performance Monitoring)
- **Special Features:** ML Kit / OCR for receipt scanning, AI-driven financial insights

## Key Features

- **OCR Bill Scanner:** Instantly scan physical receipts or bills to automatically extract transaction details, amounts, and dates, minimizing manual entry.
- **AI Smart Financial Assistant:** Get intelligent insights, spending summaries, and financial advice tailored to your spending habits.
- **Categorized Budgets:** Organize expenses into custom budget categories to monitor where your money goes in real-time.
- **Secure Authentication:** Robust user state management ensuring secure login, session persistence, and data privacy.
- **Light & Dark Mode:** Fully adaptive user interface designed for comfortable viewing in any lighting condition.

## Getting Started

To run this project locally:

1. Clone this repository:
   ```bash
   git clone [https://github.com/yourusername/your-new-repo.git]
   ```
2. Make sure you have the required Flutter and Dart versions installed, and run ```flutterfire configure
   ``` to set up your own Firebase project and generate the necessary ```firebase_options.dart``` file.
